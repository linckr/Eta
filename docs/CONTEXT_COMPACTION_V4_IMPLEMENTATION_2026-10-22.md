# v4 定稿：增长余量与无人值守开发边界

日期：2026-10-22。设计决策先冻结于此，再启动团队开发。本文覆盖 v3 关于“观测值直接等于发送护栏”的条款；2202 二次审查进一步规定独立 bootstrap、80% token提交上限及增量来源绑定，详见 [修复报告](CONTEXT_COMPACTION_V4_REVIEW_FIXES_2026-10-22.md)。实现/测试结果须逐项登记，不能把本稿当完成证明。

## 1. 四个量必须分开

- L_observed：同一路由已观察到成功请求的最大字节数，只是证据，绝不是 API 最大容量或直接发送边界。
- anchor：启用策略时冻结的基准，优先使用经确认的 L_observed；无匹配证据则固定512 KiB独立bootstrap，不从B或模型窗口推导，不伪造成功记录。
- G：为正常历史增长预留的有限策略空间，候选 `clamp(ceil(anchor/4), 256 KiB, 512 KiB)`。
- L_send_policy：用户启用此策略时冻结的 `anchor+G`（受已知 H 约束）；不是每次成功就自动提高。后续观测只更新证据，不自动滚动抬高边界。

对已冻结样本：L_observed=1,782,914 B，G=445,729 B，L_send_policy=2,228,643 B（约 2.125 MiB）。这一增长段未经真实上传验收，来源必须标为 policy_growth_allowance；不声称 API 已支持该体积。已有版本的策略值不静默迁移，候选源代码以路由显式启用/设置预览保护，手机现有配置不改。

这承认一个必要取舍：允许正常增长就需要接受有限未观测体积的风险；完全不允许越过观测值就必须在第一字节增长时阻止。设计通过可见、冻结、可回退的策略余量解决，不再混淆为“已验证安全上限”。无真实验收时只能交付待验收候选，不把这段风险藏掉。

B 仍独立：显式 B>0 且 S>B 先做软摘要；NULL/0 不派生旧字节软触发。H 已知不得越过，L_send_policy 只限制自动发送。B 高于发送边界时提示护栏先触发。允许一次越界的授权仍按 v3 绑定单次载荷，不继承下一轮。

## 2. 不在第一字节增长时重新摘要

在 token/B/H 均未触发且 S<=L_send_policy 时，即使 S>L_observed，也正常发送，不启动摘要、探测或许可弹窗。

首次因 L_send_policy 越线需整理时，目标采用：`min(floor(0.75*L_send_policy), L_send_policy-G)`，争取至少释放完整 G；token自动触发线85%，所有v4可提交候选须<=floor(80%I)，60%仅为提前达标目标。目标是压后余量，不是新的触发线。80%候选不保证有10轮token余量，只有达到60%且新增量受控时才适用相应保证。

达到目标后，固定协议与受保护部分，接续 10 轮新增总字节数<=G 时不得因发送护栏再次摘要；token 和用户显式 B 另行检验。不能用这条保证掩盖显式 B 的独立触发，也不保证任意大工具结果都可无压缩发送。

成功不滚动增加 anchor/G/L；无收益或格式错误沿持久失败分类处理。取消、存储错误和未知错误不放行，不为了目标反复重新总结同一份事实。

## 3. 团队开发切分

1. 数据/配置组：统一 B/观测/策略边界/H 的配置、Room 显式迁移及设置入口，现有字段值保持；默认旧策略，明确启用后用新策略。
2. 文本引擎组：便携文本、完成/捕获/目标分离、20,300 字符、一致断点及一次恢复；旧成果不强删、不冒充迁移。
3. 策略与恢复组：纯策略函数、增长余量、失败类别、摘要回退及最终发送校验、usage 状态与安全测试。
4. 统筹：运行/IPC 衔接、源码复审、联合回归、候选编译签名、设计/结果/待验收事项报告。

各组只编辑分配文件，接口变更先同步，集中执行完整构建。最终所有产品路径须说明生效条件；仅定义未接线的组件必须登记为未接入，不计业务功能完成。

## 4. 必过本地回归

- NULL/0/正 B 映射与边界等号；B<S<=L_send_policy 仍先软摘要。
- L_observed+1 及十轮正常增长在冻结余量内不启动护栏摘要；L_send_policy+1 才触发；最大 Int/Long 防溢出。
- 成功请求只更新 observed，不抬高已冻结发送边界；路由不匹配不复用。
- 20,300 字符完整且最终请求合格可继续；未完成响应、真实超预算、超捕获保护不得提交。
- 旧断点/新补充/取消/落盘错误保持原历史和工具结果；一次恢复不重放 Android 工具。
- Room 升级保持旧 B 与历史；DB schema 一致的回滚策略，不通过旧包降级清库。
- 失败持久化、版本失效、手动单次重试与无正文诊断；真实质量/成功率另行验收，不由合成测试代替。

45/60/90 秒仍是候选试验，不预先将 45 秒写成默认。真实模型请求、数据上传、手机安装、网络/账号配置变更均不属于本次无人值守执行；不创建定时任务，不自动向远程推送。允许本地开发、必要测试、编译及整理报告。
