# Eta 3.1.0 本地改造

## 基线与范围

- 上游基线：`v3.1.0`，提交 `84d42dc23a328502db9216bfea1fe60590b9e44c`。
- 当前本地版本：`3.1.0-local`，versionCode `2026100421`。以下按版本记录各轮验证，旧 APK 信息仅对应当轮构建。
- 迁移来源：3.0.6 本地提交 `76b54ce` 和 `edf308e`。
- 保留上游 Android 14+ 要求、包名、新 Home/聊天界面、语音能力、依赖版本和新的上下文压缩流程。

## 本地功能

1. **Codex 订阅渠道**：设备码登录、凭据刷新、Keystore 加密存储、跨进程刷新锁、账号模型目录与模型对应的思考强度。普通 OpenAI API Key 渠道独立保留；订阅 token 不写入运行配置、IPC 或日志。
2. **运行中补充指令**：主聊天与数字助理向同一活动任务追加要求；使用 runId/requestId、接收确认和去重，失败时保留输入。
3. **小布活动任务接入**：主界面查询并接入外部活动任务，显示事件重放与实时进度；查询只携带精简元数据，移除原始适配器载荷。
4. **小布会话接续**：继续发送时保留原会话和完整模型上下文；活动订阅与归档复用稳定消息 ID，保留草稿和附件，外部入口仍负责结果确认。
5. **服务连接**：绑定增加 `BIND_ABOVE_CLIENT`。这不等于已经解决 ColorOS Hans 的进程冻结。
6. **3.1.0 输入状态适配**：每会话保留独立的内存输入状态，切换页面不丢草稿；超时重试复用补充请求 ID，迟到确认不清除新文本。完成归档为活动接入消息补齐图片预览，不重复追加消息。

## 与上游的集成原则

- 保留 3.1.0 的 `TextFieldState` 输入和语音实现，将补充能力接到新 Home 入口，不恢复已删除的 Chat 页面。
- 使用上游按实际输入用量控制压缩、自动压缩开关、失败保留原文的实现，不恢复旧的自动补窗、分片重试或溢出重放。
- Codex 请求保留 `ProviderRequestPurpose`，压缩和改写仍遵循上游工具隔离与超时策略。
